# apiget compatibility

Quick reference for what currently works through the GENERIC_API connector
and what each service needed (or would need) to work end-to-end.

**Legend:** 🟢 works · 🟢 C works via a custom advanced override · 🟡 partial · 🔴 blocked · ⚪ untested · — n/a · 🔌 we have a native Scratch connector for this — listed as a compatibility benchmark only

**Columns:**

- **Pag** — pagination auto-detected by apiget
- **Auth** — auth fits a built-in style (bearer / token / raw / custom-header)
- **Scoping** — list endpoints work without required scoping query params (parent ID, filter, etc.)
- **BC** — does NOT need cursor-in-POST-body pagination (v2 feature)
- **ER** — non-2xx errors surface cleanly (some APIs return errors as HTTP 200)
